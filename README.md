# CineMe — Reverse Movie Universe

A single-file static movie discovery web app.

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API
- Clipboard API

## Run locally
Open `index.html` in a browser.

## Deploy with Netlify
1. Visit https://app.netlify.com/
2. Sign in.
3. Select **Add new site → Deploy manually**.
4. Drag the `CineMe_Hackathon` folder into the deployment area.
5. Open the generated `*.netlify.app` URL.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Select the branch containing `index.html`.
5. Save and open the generated Pages URL.

## Notes
No backend or build step is required. Favorites use LocalStorage and sharing uses the Clipboard API.
